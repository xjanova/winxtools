# คู่มือใช้งาน WinXTools (ฉบับภาษาไทย)

> WinXTools ต้องรันแบบ Administrator เสมอ (โปรแกรมจะขอสิทธิ์เองตอนเปิด)
> ทุกฟีเจอร์ในคู่มือนี้ทำงานจริงกับเครื่องของคุณ — อ่านคำเตือนของแต่ละหัวข้อก่อนกด

---

## 1. จำกัดความเร็วอินเทอร์เน็ต (Bandwidth)

WinXTools ใช้ไดรเวอร์ WinDivert (ไดรเวอร์ระดับ Kernel ที่มีลายเซ็นดิจิทัล) คุมแพ็กเก็ตจริง ไม่ใช่การหยุด/เล่นโปรแกรมสลับไปมา

### 1.1 จำกัดความเร็วทั้งเครื่อง
1. เมนู **ควบคุมแบนด์วิดท์**
2. เลื่อนแถบ **ดาวน์โหลด** / **อัปโหลด**
   - หน่วยเป็น **Mbps แบบเดียวกับแพ็กเกจเน็ต** (เน็ต 100 Mbps = เลื่อนไปที่ 100 Mbps)
   - **ขวาสุด = ไม่จำกัด** · **ซ้ายสุด = ตัดเน็ตทั้งเครื่อง** (ป้ายจะเป็นสีแดง "บล็อก")
3. ปล่อยเมาส์ ~0.5 วินาที ค่าจะถูกใช้ทันที และจำไว้ใช้ครั้งถัดไป
4. ดูป้ายสถานะมุมขวาบน:
   - 🟢 **กำลังจำกัดความเร็วจริง** = ใช้งานได้
   - 🔴 **โหลดไดรเวอร์ไม่ได้** = บันทึกค่าไว้แต่ยังไม่ได้จำกัดจริง (ดูหัวข้อแก้ปัญหา)

### 1.2 จำกัดความเร็วรายแอป
1. เมนู **ตรวจสอบเครือข่าย (Network Monitor)** → คลิกแอปที่ต้องการในรายการ
2. ที่แผง **ควบคุมความเร็วแอปนี้** ด้านขวา เลื่อนแถบ ดาวน์โหลด / อัปโหลด (หน่วย KB/s, MB/s)
   - ซ้ายสุด = ไม่จำกัด · ขวาสุด = บล็อกทิศทางนั้น
   - หรือกดปุ่มค่าด่วน: ไม่จำกัด / 10 MB/s / 5 MB/s / 1 MB/s / 512 KB/s / บล็อก
3. ทุก process ของแอปเดียวกัน (เช่น Chrome ที่มีหลาย process) **ใช้โควตาร่วมกัน** — ตั้ง 1 MB/s คือ Chrome ทั้งหมดรวมกันไม่เกิน 1 MB/s
4. คอลัมน์ **Limit** ในรายการจะแสดงค่าที่ตั้งไว้ของแต่ละแอป

### 1.3 บล็อกแอปไม่ให้ออกเน็ต
- กดปุ่ม ⛔ ท้ายแถวของแอปในหน้า Network Monitor → ยืนยัน
- ผลลัพธ์:
  - ตัดการเชื่อมต่อที่แอปใช้อยู่ **ทันที**
  - สร้างกฎ Windows Firewall ชื่อ `WinXTools_Block_<ชื่อแอป>` กันการเชื่อมต่อใหม่ — **มีผลแม้ปิด WinXTools แล้ว**
- เลิกบล็อก: กดปุ่มเดิมอีกครั้ง หรือหน้า **ควบคุมแบนด์วิดท์ → การจำกัด / บล็อกรายแอป → เลิกบล็อก**
- โปรเซสสำคัญของ Windows (svchost, lsass, Windows Defender ฯลฯ) จะบล็อกไม่ได้ เพื่อกันเครื่องพัง

### 1.4 จัดการกฎทั้งหมด
หน้า **ควบคุมแบนด์วิดท์** ด้านล่างมีรายการ **การจำกัด / บล็อกรายแอป** — เห็นทุกกฎ แม้แอปนั้นจะไม่ได้เปิดอยู่ พร้อมความเร็วที่ใช้จริงตอนนี้
- **ลบกฎ** = ยกเลิกทั้งการจำกัดและการบล็อกของแอปนั้น
- **ล้างทั้งหมด** = ลบทุกกฎรวมถึงการจำกัดทั้งเครื่อง

### 1.5 ปุ่มด่วนบน Dashboard
- **Block All** = ตัดเน็ตทั้งเครื่องทันที (ปิด WinXTools แล้วเน็ตกลับมาเอง)
- **Resume All** = ยกเลิกการตัด/จำกัดทั้งเครื่อง (กฎรายแอปยังอยู่)

### 1.6 ข้อควรรู้
- การจำกัดความเร็วทำงาน **ขณะเปิด WinXTools อยู่** (ย่อหน้าต่างไว้ได้) ส่วนการ "บล็อกแอป" ใช้ Firewall จึงมีผลตลอด
- ถ้าไม่ได้ตั้งจำกัดอะไรเลย เอนจินจะอยู่ **โหมดดูอย่างเดียว (sniff)** — ไม่ขวางแพ็กเก็ตและ **ไม่เพิ่ม ping** ให้เกม
- ความเร็วที่แสดงในรายการคือความเร็วที่แอปได้รับจริงหลังถูกจำกัดแล้ว
- เกมที่มีระบบกันโกงบางตัว (เช่น FACEIT, Vanguard/Valorant) อาจแจ้งเตือนไดรเวอร์ WinDivert → **ปิด WinXTools ก่อนเข้าเกม**
- ความแม่นยำ (ทดสอบด้วยการจำลอง): คลาดเคลื่อนไม่เกิน ~0.1% ตั้งแต่ 100 KB/s ถึง 100 MB/s และไม่เกิน ~1% ที่ 8 KB/s

### 1.7 แก้ปัญหา
| อาการ | วิธีแก้ |
|---|---|
| ป้ายขึ้น "โหลดไดรเวอร์ไม่ได้" | ปิด WinXTools แล้วเปิดใหม่ด้วยสิทธิ์ Administrator · ตรวจว่าแอนตี้ไวรัสไม่ได้กัก `WinDivert64.sys` · ปิด Memory Integrity ชั่วคราวถ้ายังไม่ได้ |
| ตั้งจำกัดแล้วความเร็วยังเกิน | ดูว่าแอปที่ใช้เน็ตจริงคือแอปไหน (เช่นดาวน์โหลดผ่าน Steam ใช้ `steam` ไม่ใช่เกม) |
| บล็อกแอปแล้วยังเข้าเน็ตได้ | แอปอาจใช้ตัวช่วยอีกไฟล์ (เช่น updater) — บล็อกไฟล์นั้นเพิ่ม |

## 2. ทำความสะอาดระบบ (Cleaner)

### วิธีใช้
1. เมนู **ทำความสะอาดระบบ** → กด **สแกน** (ยกเลิกกลางทางได้)
2. แต่ละหมวดจะแสดง:
   - **ขนาดที่ได้คืนจริง** (ขนาดบนดิสก์ ไม่นับไฟล์ที่ลบไม่ได้)
   - จำนวนไฟล์ · ไฟล์ที่ **กำลังใช้งาน (จะถูกข้าม)** · ไฟล์ใหม่ที่ **เก็บไว้** · ไฟล์ที่ระบบป้องกัน
   - คำแนะนำ เช่น "Chrome เปิดอยู่ — ปิดก่อนถ้าต้องการล้างให้หมด"
3. เปิด/ปิดหมวดที่ต้องการ (ตัวเลือกจะถูกจำไว้) — ช่อง **ขนาดที่จะได้คืน** รวมเฉพาะหมวดที่เปิด
4. กด **ทำความสะอาด** → อ่านรายการยืนยัน (มีคำเตือนของหมวดที่มีผลข้างเคียง) → ยืนยัน
5. ผลลัพธ์จะบอกทั้ง **ขนาดที่ลบจริง** และ **พื้นที่ว่างของไดรฟ์ที่เปลี่ยนไปจริง**

### หมวดที่มี
| หมวด | ค่าเริ่มต้น | หมายเหตุ |
|---|---|---|
| ไฟล์ชั่วคราว (Temp) | เปิด | เก็บไฟล์อายุไม่ถึง 24 ชม. ไว้ (โปรแกรมติดตั้งอาจยังใช้) |
| แคชเบราว์เซอร์ | เปิด | Chrome, Edge, Brave, Opera, Vivaldi, Firefox — **ไม่แตะรหัสผ่าน/คุกกี้/ประวัติ/การล็อกอิน** |
| แคชของแอป | เปิด | Discord, Teams (แบบเดิม), VS Code, Slack, Steam/Epic web cache |
| รายงานข้อผิดพลาด & Dump | เปิด | ไฟล์ WER, minidump, MEMORY.DMP |
| แคชรูปตัวอย่าง | เปิด | Windows สร้างใหม่เอง |
| ไฟล์ Log ของ Windows | เปิด | Windows\Logs |
| Delivery Optimization | เปิด | ลบด้วยคำสั่งของ Windows เอง |
| ไฟล์ดาวน์โหลด Windows Update | ปิด | ข้ามให้อัตโนมัติถ้ามีอัปเดตรอรีสตาร์ต |
| แคช Shader การ์ดจอ | ปิด | เปิดเกมครั้งแรกหลังล้างอาจกระตุกสักครู่ |
| ถังขยะ | ปิด | **ลบถาวร กู้คืนไม่ได้** |
| Windows.old | ปิด | ลบผ่าน Disk Cleanup ของ Windows · **ย้อนกลับ Windows เวอร์ชันเก่าไม่ได้อีก** |

### ความปลอดภัย
- ลบเฉพาะในโฟลเดอร์ขยะที่กำหนด ถ้าใครสร้างลิงก์ (junction/symlink) ชี้ออกไปนอกโฟลเดอร์ ระบบจะไม่ลบตาม
- ไม่ลบ Prefetch (ช่วยให้เปิดโปรแกรมเร็ว) และไม่แตะเอกสาร รูปภาพ หรือโปรแกรมที่ติดตั้ง
- **Quick Clean** บน Dashboard = ล้างเฉพาะหมวดที่ปลอดภัย (Temp, แคชเบราว์เซอร์, แคชรูปตัวอย่าง, รายงานข้อผิดพลาด)

## 3. พร็อกซีฟรี (เดิมชื่อ Proxy / VPN)

> **นี่ไม่ใช่ VPN** — WinXTools ไม่ได้เข้ารหัสข้อมูล พร็อกซีฟรีเป็นของบุคคลที่ไม่รู้จัก ซึ่งเห็นได้ว่าคุณเข้าเว็บอะไร **อย่าล็อกอินบัญชีสำคัญ** (ธนาคาร อีเมลงาน) ระหว่างใช้

1. เมนู **พร็อกซีฟรี** → เลือกประเทศ → กด **เชื่อมต่อ**
2. WinXTools จะทดสอบพร็อกซีหลายตัวพร้อมกันผ่าน **HTTPS** แล้วเลือกตัวที่ใช้ได้จริงและออกเน็ตที่ประเทศที่เลือก
   - ถ้าเจอแต่ตัวที่ออกประเทศอื่น จะถามก่อน และแสดงประเทศขาออกจริงเป็นสีส้ม
3. มีผลเฉพาะแอปที่ใช้การตั้งค่าพร็อกซีของ Windows (เบราว์เซอร์ส่วนใหญ่) — เกมและแอปอื่นยังต่อเน็ตตรงตามปกติ
4. เว็บในบ้าน/ออฟฟิศ (router, NAS, 192.168.x.x) ไม่ผ่านพร็อกซี
5. กด **ยกเลิกการเชื่อมต่อ** → ค่าพร็อกซีเดิมของคุณ (รวมพร็อกซีบริษัท/PAC/Auto-detect) ถูกคืนครบ
6. ปลอดภัยแม้แอปปิดผิดปกติ: ปิด WinXTools, logoff หรือแอป crash ระหว่างเชื่อมต่อ → ค่าเดิมจะถูกคืนตอนปิด หรืออย่างช้าตอนเปิด WinXTools ครั้งถัดไป
7. ระหว่างเชื่อมต่อ ระบบเช็คพร็อกซีทุก 60 วินาที ถ้าล่มจะเตือนสีส้ม (ไม่สลับไปต่อตรงเองโดยที่คุณไม่รู้)

## 4. RAM / Auto-Kill / Smart Kill

> สรุปสั้น: กด **ล้างหน่วยความจำตอนนี้** ได้เลย ค่าเริ่มต้นเป็นแบบ **ปลอดภัย** (ไม่แตะโปรแกรมใดเลย)
> ตัวเลข "คืนได้" ที่แสดงคือค่าที่ **วัดจริง** หลังล้าง ไม่มีการปัดหรือแต่งตัวเลข

### 4.1 อ่านตัวเลขบนหน้า RAM
| ช่อง | ความหมาย |
|---|---|
| **หน่วยความจำทั้งหมด** | RAM ที่ Windows ใช้ได้จริง อาจน้อยกว่าที่ติดตั้งเล็กน้อย (บรรทัดเล็ก "จากที่ติดตั้ง …") เพราะฮาร์ดแวร์/การ์ดจอออนบอร์ดจองไว้ |
| **ใช้งานอยู่** | ทั้งหมด − พร้อมใช้งาน (ตรงกับ % การใช้งาน) · บรรทัด "จองแล้ว A / B GB" = หน่วยความจำที่โปรแกรมจองไว้ (Commit) เทียบกับเพดานที่ Windows ให้จองได้ |
| **พร้อมใช้งาน** | RAM ที่โปรแกรมหยิบไปใช้ได้ทันที = **ว่าง + แคช** (แสดงแยกไว้ใต้ตัวเลข) |
| **การใช้งาน** | % ที่ Windows รายงาน (เท่ากับที่ Task Manager แสดง) |

**แถบ "RAM ถูกใช้ไปกับอะไรบ้าง"** อ่านค่าตรงจาก Windows (ไม่ต้องใช้ Performance Counter)
- **กำลังใช้งาน** — โปรแกรมและ Windows ใช้อยู่จริง · บรรทัด **บีบอัดไว้** = RAM ที่ Windows ใช้เก็บข้อมูลแบบบีบอัด (นับรวมอยู่ในกำลังใช้งานแล้ว)
- **รอเขียนลงดิสก์ (Modified)** — ข้อมูลที่แก้แล้วแต่ยังไม่ได้บันทึกลงดิสก์
- **แคช (Standby)** — ไฟล์/โปรแกรมที่เคยเปิด Windows เก็บไว้เผื่อใช้อีก · "(สำคัญน้อย …)" = ส่วนที่ Windows เองจัดว่าสำคัญน้อยที่สุด
- **ว่าง** — ไม่มีอะไรใช้เลย

> แคชเยอะเป็นเรื่องปกติและ **ไม่ใช่ RAM ที่เสียเปล่า** — Windows ยกแคชให้โปรแกรมที่ขอหน่วยความจำได้ทันที เครื่องที่ "ว่าง" เหลือน้อยแต่แคชเยอะจึงยังไม่ใช่เครื่องที่ RAM เต็ม

**รายการโปรแกรมที่ใช้หน่วยความจำสูงสุด**
- **RAM ที่ใช้** = RAM ที่โปรเซสนั้นใช้เอง (ตัวเลขเดียวกับคอลัมน์ "หน่วยความจำ" ใน Task Manager) · **จองไว้** = หน่วยความจำส่วนตัวที่จองไว้ รวมส่วนที่ถูกย้ายไปไฟล์เพจแล้ว
- ปุ่ม 🧹 **ลด RAM** เฉพาะโปรแกรมนั้น — ผลขึ้นเหนือรายการ เช่น "chrome: ใช้ RAM 812 MB → 35 MB" (โปรแกรมจะโหลดส่วนที่ต้องใช้กลับมาเองเมื่อใช้งาน)
- ปุ่ม ✕ **ปิดโปรเซส** — ถามยืนยันทุกครั้ง ปิดเฉพาะโปรเซสนั้น (ไม่ปิดโปรเซสลูก) งานที่ยังไม่บันทึกจะหาย
  - ถ้ารายการเก่าและโปรแกรมนั้นปิดไปแล้ว จะแจ้ง "ปิดไปก่อนแล้ว — ไม่ได้ทำอะไร" **ไม่มีทางปิดผิดตัว** แม้ Windows เอาหมายเลข PID ไปให้โปรแกรมอื่นแล้ว
- ปุ่มที่ **จางลง** = โปรเซสของ Windows (เช่น dwm, csrss, Memory Compression, Windows Defender) หรือ WinXTools เอง — กดไม่ได้เพื่อกันเครื่องพัง
- รายการไม่รีเฟรชเองระหว่างที่คุณกำลังจะกดปุ่ม (กันแถวเลื่อนแล้วกดผิดแถว) — กด **รีเฟรช** เมื่อต้องการ

### 4.2 ปุ่ม "ล้างหน่วยความจำตอนนี้"
1. ทำตามรายการที่เปิดไว้ใน **สิ่งที่จะล้าง** (ค่าเริ่มต้น 2 รายการที่ปลอดภัย)
2. ทำงานเบื้องหลัง หน้าไม่ค้าง · กดซ้ำระหว่างทำงานจะไม่เริ่มรอบใหม่ (ถ้ามีรอบอื่นทำงานอยู่ เช่น รอบอัตโนมัติ จะแสดงผลของรอบนั้นพร้อมบอกให้รู้)
3. ออกจากหน้านี้ระหว่างล้างได้ งานทำต่อจนเสร็จ กลับมาดูผลได้ในหน้าเดิม
4. ผลลัพธ์แสดงเป็น
   - บรรทัดสรุป เช่น **พร้อมใช้งาน +312 MB · ว่าง 310 MB → 2.33 GB**
   - แต่ละรายการมี ✓ สำเร็จ / ✗ ไม่สำเร็จ พร้อมเหตุผลภาษาไทย (เช่น "Windows ไม่ให้สิทธิ์ที่จำเป็น")

**"คืนหน่วยความจำ" แปลว่าอะไรจริงๆ**
- **พร้อมใช้งาน +X** = RAM ที่โปรแกรมใช้ได้ **เพิ่มขึ้นจริง** วัดหลังล้างเสร็จครึ่งวินาที
- **ว่าง A → B** = แคชถูกคืนเป็นหน่วยความจำว่าง การล้างแคช **ไม่ทำให้ "พร้อมใช้งาน" เพิ่ม** เพราะแคชนับเป็นพร้อมใช้งานอยู่แล้ว — สิ่งที่ได้คือพื้นที่ว่างสำหรับโปรแกรมที่จะเปิดใหม่ทันที
- ถ้าขึ้น **"ไม่เพิ่มขึ้น"** แปลว่าระหว่างนั้นโปรแกรมอื่นใช้ RAM เพิ่มพอๆ กับที่คืนได้ — WinXTools บอกตามจริง ไม่เอาตัวเลขประมาณมาโชว์
- ถ้าทุกรายการไม่สำเร็จ จะขึ้น **"ไม่ได้ล้างอะไรเลย"** แทนตัวเลข

### 4.3 สิ่งที่จะล้าง — เลือกอะไรดี
| รายการ | ทำอะไร | ป้าย | ค่าเริ่มต้น |
|---|---|---|---|
| เขียนข้อมูลที่ค้างอยู่ลงดิสก์ | เขียนส่วน "รอเขียนลงดิสก์" ลงดิสก์ ให้กลับมาพร้อมใช้งาน · เครื่องที่ใช้ HDD ดิสก์อาจทำงานหนักชั่วครู่ | ปลอดภัย | เปิด |
| แคชที่สำคัญน้อย | คืนแคชส่วนที่ Windows จัดว่าสำคัญน้อยที่สุด | ปลอดภัย | เปิด |
| แคชทั้งหมด (Standby) | คืนแคชทั้งหมดแบบโปรแกรม ISLC · หลังล้าง โปรแกรม/เกมต้องอ่านไฟล์จากดิสก์ใหม่ จึงโหลดช้าลงเล็กน้อย | ควรระวัง | ปิด |
| รวมหน้าหน่วยความจำที่ซ้ำกัน | ให้ Windows เก็บข้อมูลที่เหมือนกันไว้ชุดเดียว (Windows 10 ขึ้นไป) · ใช้ CPU หนักสักครู่ | ควรระวัง | ปิด |
| แคชไฟล์ของระบบ | ย้ายแคชไฟล์ของ Windows ออกจากหน่วยความจำที่ใช้งานอยู่ | ควรระวัง | ปิด |
| ลด RAM ของโปรแกรมเบื้องหลัง | ย้ายหน่วยความจำของโปรแกรมเบื้องหลังที่ว่างอยู่ออกจาก RAM · สลับกลับไปใช้แล้วอาจกระตุกชั่วครู่ | แรง | ปิด |

- เปิด **แคชทั้งหมด** แล้ว "แคชที่สำคัญน้อย" จะถูกล็อกไว้ เพราะรวมอยู่ในนั้นแล้ว
- ปุ่ม **ใช้ค่าปลอดภัย** = กลับไปใช้ 2 รายการแรก
- ลำดับการทำงานคงที่: รวมหน้าที่ซ้ำ → ลด RAM โปรแกรม → แคชไฟล์ระบบ → เขียนข้อมูลค้าง → ล้างแคช

**"ลด RAM ของโปรแกรมเบื้องหลัง" จะไม่แตะ**
- โปรแกรมที่อยู่หน้าจอตอนนั้น **รวมทุกโปรเซสของโปรแกรมเดียวกัน** (เช่น Chrome ทุกแท็บ)
- WinXTools เอง (ไม่ให้หน้าต่างนี้กระตุก), โปรเซสของ Windows (Explorer, dwm, เสียง, คีย์บอร์ด ฯลฯ), บริการของ Windows และโปรแกรมของผู้ใช้อื่น
- โปรแกรมที่กำลังใช้ CPU อยู่ขณะนั้น และโปรแกรมที่ใช้ RAM น้อยมาก
- โปรแกรมที่คุณพิมพ์ไว้ในช่อง **ห้ามลด RAM ของโปรแกรมเหล่านี้** (คั่นด้วยจุลภาค ไม่ต้องมี .exe เช่น `discord, spotify, obs64`) — ชื่อที่ไม่ถูกต้องจะไม่ถูกบันทึกและแจ้งให้ทราบ
- ⚠️ เกมที่มีระบบกันโกง: อย่าเปิดตัวเลือกนี้ขณะเปิดเกมค้างไว้เบื้องหลัง หรือใส่ชื่อเกมไว้ในช่องห้ามลด

**ใช้แบบไหนเมื่อไร**
- ใช้ทั่วไป → ค่าปลอดภัยพอ
- เกมกระตุก ทั้งที่ "ว่าง" เหลือใกล้ 0 แต่แคชเยอะ → เปิด **แคชทั้งหมด** (หรือใช้เงื่อนไขแบบ ISLC ในหัวข้อ 4.4)
- RAM เต็มจริงๆ (การใช้งาน 90% ขึ้นไป) ก่อนเปิดโปรแกรมหนัก → เปิด **ลด RAM ของโปรแกรมเบื้องหลัง** ชั่วคราว แล้วกดล้าง

### 4.4 ล้างอัตโนมัติ
- ตรวจหน่วยความจำทุก 5 วินาที (เบามาก) และล้างเฉพาะเมื่อเข้าเงื่อนไข **2 ครั้งติดกัน** (กันค่าที่พุ่งขึ้นชั่วขณะ)
- **เงื่อนไข 1 — เมื่อใช้หน่วยความจำถึง X%** → ล้างตามรายการใน "สิ่งที่จะล้าง"
- **เงื่อนไข 2 — เมื่อหน่วยความจำว่างเหลือน้อย (แบบ ISLC)** → ถ้า "ว่าง" ต่ำกว่าค่าแรก **และ** แคชมีอย่างน้อยเท่าค่าที่สอง จะล้างแคชทั้งหมด
- **รอหลังการล้างครั้งล่าสุดอย่างน้อย N นาที** — กันล้างถี่เกินไป นับรวมตอนที่คุณกดล้างเองด้วย
- เปิดโหมดอัตโนมัติแต่ปิดทั้ง 2 เงื่อนไข จะมีคำเตือนสีส้ม (จะไม่มีการล้างใดๆ)
- ค่าที่แนะนำ: ใช้ทั่วไป 85% / รอ 30 นาที · สายเกม (แบบ ISLC) ว่างต่ำกว่า 1 GB + แคชอย่างน้อย 1 GB / รอ 5 นาที
- ทำงานต่อแม้ปิดหน้า RAM และเปิดแอปใหม่ · การตั้งค่าเก็บในโฟลเดอร์ที่มีแต่ admin แก้ได้
- ทุกครั้งที่ล้างอัตโนมัติ จะอยู่ใน **ประวัติการทำงาน** พร้อมเหตุผล เช่น "อัตโนมัติ – ใช้หน่วยความจำ 91%"
- หมายเหตุสำหรับผู้ใช้เดิม: ช่อง "ช่วงเวลาตรวจสอบ" เดิมกลายเป็น "รอหลังการล้างครั้งล่าสุด" (ค่าเดิมยังอยู่) — ตอนนี้ตรวจถี่ขึ้นแต่ล้างไม่ถี่กว่าเดิม

### 4.5 Smart Kill / Auto Kill
- **Auto Kill**: ปิดโปรแกรมในรายการทันทีและทุกครั้งที่มันเปิดขึ้นมา **เฉพาะในบัญชีผู้ใช้ของคุณ** (ไม่แตะบริการของ Windows และโปรแกรมของผู้ใช้อื่น)
  - เพิ่มกฎ = ถามยืนยันก่อน และถ้าโปรแกรมนั้นเปิดอยู่จะถูกปิดทันที · เปิด Auto Kill = ถามยืนยันพร้อมรายชื่อ
  - ตัวเลข ×N ข้างชื่อ = จำนวนครั้งที่ถูกปิด · ลบกฎได้ด้วยปุ่มถังขยะ (ไม่ต้องยืนยัน เพราะไม่มีอะไรถูกปิด)
- **Smart Kill**: ปิดโปรแกรมที่หน้าต่าง "ไม่ตอบสนอง" ต่อเนื่อง **60 วินาทีขึ้นไป**
  - ไม่ปิดเด็ดขาด: โปรแกรมที่คุณกำลังใช้อยู่ตรงหน้า, โปรเซสของ Windows/Explorer, WebView2 (Outlook/Teams), WinXTools เอง
  - ปิดเฉพาะโปรเซสนั้น ไม่ปิดโปรเซสลูก และปิดเฉพาะตัวที่ค้างจริง (ถ้าโปรแกรมปิดไปแล้วและ PID ถูกใช้ใหม่ จะไม่ถูกปิดแทน)
  - **ไม่ปิดโปรแกรมเพราะใช้ RAM เยอะ** — เวอร์ชันก่อนเคยปิดโปรแกรมบางตัวที่เกิน 2 GB โดยไม่บอก (รวมถึงตัวอัปเดต) ตอนนี้เอาออกแล้ว
- ทุกครั้งที่ปิดอัตโนมัติ จะมีกล่องแจ้งเตือนมุมขวาล่าง และบันทึกใน **ประวัติการทำงาน** ของหน้า RAM
- งานที่ยังไม่บันทึกในโปรแกรมที่ถูกปิดจะหาย — เปิด Smart Kill / Auto Kill เฉพาะเมื่อต้องการจริง

### 4.6 ข้อควรรู้
- **RAM ว่างเยอะไม่ได้แปลว่าเครื่องเร็วขึ้นเสมอ** — Windows ตั้งใจใช้ RAM ที่ว่างเป็นแคชเพื่อให้เปิดโปรแกรมเร็ว การล้างบ่อยๆ ทำให้ต้องอ่านจากดิสก์ใหม่ ช้าลงได้
- ล้างเมื่อมีเหตุ: ก่อนเปิดเกม/โปรแกรมหนักในเครื่อง RAM น้อย, เกมกระตุกทั้งที่แคชเยอะแต่ว่างเหลือน้อย, หรือ RAM เต็มจริง
- การล้างทุกแบบ **ไม่ทำให้ข้อมูลหาย** (ต่างจากการปิดโปรเซส) — ผลข้างเคียงมีแค่ความช้าชั่วครู่ตามป้ายของแต่ละรายการ
- ต้องรัน WinXTools แบบ Administrator (ปกติแอปขอสิทธิ์เองตอนเปิด) ถ้าไม่ใช่ จะมีแถบสีส้มบอก และปุ่มล้างจะกดไม่ได้

| อาการ | วิธีแก้ |
|---|---|
| ✗ "Windows ไม่ให้สิทธิ์ที่จำเป็น" | ปิด WinXTools แล้วเปิดใหม่แบบ Administrator · ในเครื่องบริษัท ผู้ดูแลระบบอาจปิดสิทธิ์ "Profile single process" ไว้ |
| ✗ "Windows เวอร์ชันนี้ไม่รองรับ" (รวมหน้าที่ซ้ำ) | ปิดรายการนั้นไป — ใช้ได้เฉพาะ Windows 10 ขึ้นไป และเมื่อ Windows เปิดความสามารถนี้ไว้ |
| ล้างแล้ว "พร้อมใช้งาน" ไม่เพิ่ม | ปกติถ้าเลือกแค่ล้างแคช (แคชนับเป็นพร้อมใช้งานอยู่แล้ว) ดูที่ "ว่าง A → B" แทน |
| สลับกลับไปโปรแกรมแล้วกระตุก | ปิด "ลด RAM ของโปรแกรมเบื้องหลัง" หรือใส่ชื่อโปรแกรมนั้นในช่องห้ามลด |
| ดิสก์ทำงานหนักหลังกดล้าง | เกิดจาก "เขียนข้อมูลที่ค้างอยู่ลงดิสก์" บนเครื่อง HDD — รอสักครู่ หรือปิดรายการนั้น |

## 5. ปรับแต่ง Windows (Windows Optimizer)

- ปิด service / ฟีเจอร์ที่ไม่ใช้ได้ทีละรายการหรือแบบชุด (**Safe Optimize**)
- ก่อนเปลี่ยน ระบบพยายามสร้าง **System Restore Point** และบอกผลจริง (Windows สร้างได้วันละครั้ง ถ้าเพิ่งสร้างไปจะแจ้งว่าใช้จุดเดิมได้)
- **Restore / เปิดกลับ**: คืนค่าการเริ่มทำงานเดิมของแต่ละ service ตามที่บันทึกไว้ก่อนปิด (เช่น Automatic (Delayed)) และสั่งให้ทำงานต่อ — ไม่ใช่ตั้งเป็น Manual ทุกตัวแบบเดิม
- Service ที่ไม่มีในเครื่องจะไม่แสดง และไม่นับเป็น error
- ตัวเลข "~X MB" เป็น **ค่าประมาณ** จากการใช้งานทั่วไป ไม่ได้วัดจากเครื่องคุณ
- หมายเหตุ: ถ้าใช้เครื่องอ่านบัตรประชาชน อย่าปิด "Smart Card" (SCardSvr)

## 6. เครื่องมือเครือข่าย / ตรวจการเชื่อมต่อ / แพ็กเก็ต

- **เครื่องมือเครือข่าย**: ทุกเครื่องมือกด Execute ได้แล้ว (My IP, ARP, Route, Speed Test, Network Stats ที่เคยไม่มีปุ่ม) มีปุ่ม **Cancel** และหยุดเองเมื่อออกจากหน้า
  - Traceroute แสดงเวลาต่อ hop จริง และ `*` เมื่อ hop ไม่ตอบ
  - SSL Checker บอก [ถูกต้อง]/[คำเตือน]/[ไม่ถูกต้อง]/[หมดอายุ] ตามการตรวจใบรับรองจริง พร้อมเหตุผล
  - FLOOD (Packet Sender) จำกัดไม่เกิน 10,000 แพ็กเก็ต — ใช้กับเครื่องของตัวเองเท่านั้น
- **ตรวจการเชื่อมต่อ (Connections)**: ชื่อโฮสต์ค้นหาเบื้องหลัง หน้าไม่ค้าง · ตัวกรอง UDP ใช้ได้ · IP ที่บล็อกไว้ **ยังอยู่หลังรีสตาร์ท** และแสดงเป็นแถว "Blocked" ให้กด Unblock ได้
- **ตรวจแพ็กเก็ต (Packets)**: เลือกแพ็กเก็ตแล้ว Block IP / Copy ได้จริง รายการไม่หลุดการเลือกระหว่างจับแพ็กเก็ต

## 7. ถอนการติดตั้งโปรแกรม (Uninstaller)

- รายการโปรแกรมครบเหมือนหน้า "แอป" ของ Windows รวมโปรแกรมที่ติดตั้งเฉพาะบัญชีคุณ (เช่น VS Code, Discord, Zoom) — ป้าย "เฉพาะผู้ใช้นี้"
- **ถอนการติดตั้ง**: เปิดตัวถอนของโปรแกรมเอง → WinXTools รอจนเสร็จ → ตรวจว่าโปรแกรมหายจริงแล้วแจ้งผล
- **ทำความสะอาดลึก (Deep Clean)** — ทำตามลำดับนี้เท่านั้น:
  1. ถอนการติดตั้งด้วยตัวถอนของโปรแกรมและรอจนเสร็จ
  2. ตรวจว่าโปรแกรมถูกถอนออกจริง — **ถ้ายังติดตั้งอยู่ จะหยุดทันทีโดยไม่แตะไฟล์ใดๆ**
  3. ค้นหาโฟลเดอร์ตกค้างที่ตรงกับโปรแกรมพอดี (โฟลเดอร์ที่ติดตั้ง / ชื่อตรงกันใน Program Files, ProgramData, AppData)
  4. แสดงทุกรายการพร้อมขนาด **ให้คุณติ๊กเลือกเอง** (ไม่มีการเลือกไว้ให้ล่วงหน้า)
  5. โฟลเดอร์ที่เลือกจะถูก **ย้ายไปถังขยะ** — กู้คืนได้
- ระบบจะไม่ยอมแตะ: โฟลเดอร์ Windows / Program Files ทั้งก้อน / โปรไฟล์ผู้ใช้ / เอกสาร / โฟลเดอร์ของโปรแกรมอื่นที่ยังติดตั้งอยู่ / junction-symlink
- โปรแกรมที่ติดตั้งเฉพาะผู้ใช้ ตัวถอนจะรันด้วยสิทธิ์ผู้ใช้ปกติ (ไม่ใช่ admin) เพื่อความปลอดภัย

## 8. ตั้งค่า (Settings)

- **ภาษา**: เลือกไทย/อังกฤษ/อัตโนมัติ — จำค่าไว้ เปิดแอปครั้งหน้าใช้ภาษาเดิม
- **เริ่มพร้อม Windows**: สร้าง Task Scheduler ให้เปิด WinXTools (สิทธิ์ admin) ตอนล็อกอิน โดยไม่มีหน้าต่าง UAC
  - ใช้ได้เมื่อวาง WinXTools ไว้ในโฟลเดอร์ที่มีแต่ admin แก้ได้ เช่น `C:\Program Files\WinXTools` (กันโปรแกรมอื่นแอบเปลี่ยนไฟล์แล้วได้สิทธิ์ admin)
- **ตรวจสอบอัปเดต**: บอกตามจริง — ถ้าตรวจไม่ได้จะขึ้นว่า "ตรวจสอบอัพเดทไม่สำเร็จ" ไม่ใช่ "เป็นเวอร์ชันล่าสุด"
  - ตัวติดตั้งอัปเดตตรวจไฟล์ (ขนาด, SHA-256, **ลายเซ็นของ xman studio**) และติดตั้งจากโฟลเดอร์ที่มีแต่ admin เข้าถึงได้ — รายละเอียดดูข้อ 12
- **ใบอนุญาต (License)**: ใส่คีย์ / ย้ายเครื่อง / ถอดออก / ตรวจสอบอีกครั้ง / ซื้อ Pro — ดูข้อ 12
- **รีเซ็ตการตั้งค่า**: คืนภาษาเป็นอัตโนมัติ + ปิดเริ่มพร้อม Windows (กฎแบนด์วิดท์ไม่ถูกลบ — ลบได้ที่หน้า ควบคุมแบนด์วิดท์ › ล้างทั้งหมด)

## 9. กฎอัตโนมัติ (Automation Rules) — Pro

ระบบตรวจกฎทุก 5 วินาทีตั้งแต่เปิดแอป (ของเดิมไม่เคยทำงานเลย)

**สร้างกฎ**: เมนู **ระบบอัตโนมัติ** → เพิ่มกฎ → ตั้ง *เงื่อนไข* (เช่น แอปกำลังเปิด, ความเร็วเน็ตเกิน X, ช่วงเวลา/วันในสัปดาห์, จำนวนการเชื่อมต่อ, หรือ "ทุกครั้งที่เริ่มกฎ") → ตั้ง *การกระทำ*:
- บล็อก/เลิกบล็อก IP, บล็อก/เลิกบล็อกพอร์ต (TCP/UDP)
- จำกัดความเร็ว (KB/s) ของแอปหรือทั้งเครื่อง / ยกเลิกการจำกัด
- ปิดแอป (โปรแกรมระบบและ WinXTools ปิดไม่ได้)
- แจ้งเตือนบนหน้าจอ (กล่องเล็กมุมขวาล่าง ไม่แย่งโฟกัส)
- เขียน log ลงไฟล์ (เก็บที่ `C:\ProgramData\WinXTools\Logs` เท่านั้น)
- ส่ง Webhook

**พฤติกรรมสำคัญ**
- กฎทำงาน **ครั้งเดียวตอนเงื่อนไขเริ่มเป็นจริง** ไม่ยิงซ้ำทุก 5 วินาทีระหว่างที่ยังจริงอยู่ และมี **ระยะพัก (cooldown)** ค่าเริ่มต้น 60 วินาที
- ตัวอย่าง: "ถ้า Steam เปิด → จำกัด Steam 2 MB/s" + อีกกฎ "ถ้า Steam ปิด → ยกเลิกจำกัด" (กฎไม่ยกเลิกเองเมื่อเงื่อนไขหมด ต้องสร้างกฎคู่)
- หน้า Automation แสดงว่าแต่ละกฎรันไปกี่ครั้ง ล่าสุดเมื่อไร สำเร็จ/ล้มเหลวกี่รายการ และมีบันทึกกิจกรรมของรอบใช้งานนี้
- กฎที่ย้ายมาจากเวอร์ชันเก่าจะถูก **ปิดไว้ก่อน** ให้ตรวจแล้วเปิดเอง
- LINE Notify (LINE ปิดบริการแล้ว), SMS, Email และ "รันคำสั่ง" ถูกนำออก (ใช้ไม่ได้จริง/ไม่ปลอดภัย)
- ไฟล์กฎเก็บในโฟลเดอร์ที่มีแต่ admin แก้ได้ กันโปรแกรมอื่นแอบเพิ่มกฎ

## 10. เทคนิค Windows (Windows Tricks)

หน้านี้มี 100+ เทคนิค แบ่ง 12 หมวด: เกม · Explorer และแถบงาน · หน้าตาและการใช้งาน · ความเป็นส่วนตัวและโฆษณา · ประสิทธิภาพ · พลังงานและการเปิดเครื่อง · เครือข่าย · Windows Update · ความปลอดภัย · พื้นที่จัดเก็บ · ซ่อม/รายงาน · เครื่องมือ

### อ่านการ์ดยังไง
- **จุดสถานะ** ใต้ชื่อ: `✓ ปรับแต่งแล้ว` / `ค่าเริ่มต้นของ Windows` / `ตั้งค่าเอง` / `ไม่รองรับเครื่องนี้` — อ่านจากเครื่องคุณจริงทุกครั้งที่เปิดหน้าและหลังกดปุ่ม
- **ใช้งาน** = เปิดเทคนิคนั้น · **คืนค่าเริ่มต้น** = กลับเป็นค่าที่ Windows ตั้งมาจริง (ลบค่าที่เพิ่มไว้ ไม่ใช่ใส่ค่าเดาๆ)
- บรรทัดสีฟ้า "ต้องรีสตาร์ท Explorer / ต้องรีสตาร์ทเครื่อง" — หลังกดจะมีแถบด้านบนพร้อมปุ่มรีสตาร์ทให้
- ป้ายความเสี่ยง: ปลอดภัย / ควรระวัง / อันตราย — ระดับที่เสี่ยงจะถามยืนยันพร้อมคำอธิบายผลข้างเคียงก่อนเสมอ
- เครื่องมือแบบ "รัน" (เช่น ล้าง DNS, ซ่อมไฟล์ระบบ, รายงานระบบ) จะแสดงผลลัพธ์ในหน้าต่างของแอป มีปุ่มคัดลอก และยกเลิกได้ถ้าทำงานนาน
- แถบเหลืองด้านบนจะเตือนถ้า WinXTools ไม่ได้รันแบบ Administrator

### เทคนิคแนะนำ
| เป้าหมาย | เทคนิค |
|---|---|
| เล่นเกมลื่นขึ้น | **โหมดเกมเมอร์** (กดครั้งเดียว บันทึกค่าเดิมไว้ คืนค่าได้ครบ) · ปิด Game DVR · Fullscreen Optimizations · HAGS (ถ้าการ์ดจอรองรับ) |
| Explorer ใช้ง่าย | แสดงนามสกุลไฟล์ · แสดงไฟล์ซ่อน · เปิดที่ "พีซีเครื่องนี้" · เมนูคลิกขวาแบบเดิม · "สิ้นสุดงาน" บนแถบงาน |
| ลดโฆษณา/ความรำคาญ | ปิดคำแนะนำในเมนูเริ่ม · ปิดโฆษณาหน้าล็อก · ปิดคำแนะนำของ Windows · ปิด Advertising ID · ปิดผลค้นหาเว็บในเมนูเริ่ม |
| ความเร็วเน็ต/แก้เน็ต | ล้าง DNS · รีเซ็ต Winsock · ต่ออายุ IP · ใช้ DNS Cloudflare (คืนค่า DNS เดิมได้ทุกการ์ดเครือข่าย) · ให้ IPv4 มาก่อน IPv6 |
| อัปเดตไม่กวน | ไม่อัปเดตไดรเวอร์อัตโนมัติ · ไม่รีสตาร์ทเองขณะใช้งาน (Pro) · ค้างเวอร์ชัน Windows (Pro) · หยุดอัปเดตชั่วคราว (เปิดหน้า Settings) |
| พื้นที่ดิสก์ | ล้าง Component Store (DISM) · Compact OS (SSD เล็ก) · ปิด Reserved Storage · ไปหน้า Cleaner |
| ซ่อม Windows | ซ่อมไฟล์ระบบ (DISM → SFC) · ตรวจดิสก์แบบออนไลน์ · รายงานแบตเตอรี่/พลังงาน (ไฟล์ไปอยู่บน Desktop) |

### สิ่งที่ถูกนำออก (เพราะไม่มีผลจริง)
SystemResponsiveness=0 (Windows ปัดกลับเป็น 20), Win32PrioritySeparation 0x26 (เท่ากับค่าเดิม), ปิด Nagle, ปุ่ม Kill Process ตัวอย่าง, ปุ่มล้างแคช 5 ตัวที่ซ้ำกับหน้า Cleaner (ตัวเก่าลบประวัติอัปเดตด้วย) — และ Widgets กับ Copilot ที่ Windows บล็อกการแก้ด้วยโปรแกรม จะเป็นปุ่มพาไปหน้า Settings แทน
